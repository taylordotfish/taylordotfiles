Dependencies
============

taylordotfiles requires the following dependencies. Here, Debian package names
are used.

Base:

* awk
* bc
* gcc
* jq
* m4
* make
* lua5.3
* python3

Graphical environment:

* argyll
* brightnessctl (if laptop)
* feh
* gnome-icon-theme
* hsetroot
* i3
* libx11-dev
* libxinerama-dev
* libxrandr-dev
* logrotate
* lxpolkit
* pulseaudio-utils
* picom
* rxvt-unicode
* xcape
* xsel
* xsettingsd

Optional:

* cmark or pulldown-cmark
* libpulse-dev
* rsync
